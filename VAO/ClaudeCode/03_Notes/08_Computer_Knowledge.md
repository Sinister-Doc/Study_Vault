## 1. Computer Fundamentals (ಕಂಪ್ಯೂಟರ್ ಅವಧಾರಣೆಗಳು)

### Hardware (ಯಾಂತ್ರಾಂಗ)

- **Input devices**: Keyboard, mouse, scanner, microphone, webcam, touch screen
- **Output devices**: Monitor, printer, speaker
- **Storage devices**: Hard disk (HDD), Solid State Drive (SSD), pen drive, CD/DVD, memory card
- **Processing unit**: CPU (Central Processing Unit) — the brain of the computer
- **Motherboard**: Main circuit board connecting all components
- **RAM**: Random Access Memory — temporary memory, data lost when power off
- **ROM**: Read Only Memory — permanent, stores BIOS

> [!example] Likely Questions / PYQ
> Q: What does CPU stand for? — Central Processing Unit
> Q: Which memory is volatile? — RAM
> Q: What is the full form of UPS? — Uninterruptible Power Supply

### Software (ತಂತ್ರಜ್ಞಾನ)

- **System software**: Operating System (Windows, Linux, macOS) — manages hardware + software
- **Application software**: MS Word, Excel, PowerPoint, browsers, media players
- **Utility software**: Antivirus, disk cleanup, backup tools
- **Firmware**: Embedded software in hardware (e.g., BIOS)

> [!example] Likely Questions / PYQ
> Q: Which is system software? — Operating System
> Q: MS Word is an example of? — Application software

## 2. Operating System & GUI (ಓಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್)

- **Windows**: Most common desktop OS
- **Linux**: Open-source OS (Ubuntu, Fedora)
- **macOS**: Apple's OS
- **Android**: Mobile OS by Google
- **iOS**: Mobile OS by Apple

### GUI Components (ಗ್ರಾಫಿಕಲ್ ಯೂಜ಼ರ್ ಇಂಟರ್‌ಫೇಸ್)

- **Desktop**: Main screen with icons
- **Taskbar**: Bottom bar with open applications
- **Start Menu**: Launches programs
- **Window**: A rectangular area showing a program
- **Icon**: Small picture representing a file/program

## 3. Internet & Email (ಇಂತರ್ಜಾಲ & ಇಮೇಲ್)

- **Internet**: Global network of computers
- **WWW (World Wide Web)**: System of interlinked hypertext documents
- **Browser**: Software to access the internet (Chrome, Firefox, Edge, Safari)
- **Email**: Electronic mail — Gmail, Outlook, Yahoo Mail
- **Social Media**: Facebook, Twitter/X, WhatsApp, Instagram, YouTube
- **E-commerce**: Online shopping (Amazon, Flipkart)
- **E-governance**: Government services online (e-Karnataka, Aadhaar, passport application)

> [!example] Likely Questions / PYQ
> Q: What is the full form of WWW? — World Wide Web
> Q: Chrome is a — Browser
> Q: Email stands for — Electronic mail

### Digital Initiatives in Karnataka (ಕರ್ನಾಟಕದ ಡಿಜಿಟಲ್ ಯೋಜನೆಗಳು)

- **e-Karnataka**: Integrated governance portal
- **Aadhaar**: 12-digit unique identity number
- **DigiLocker**: Digital document wallet
- **UMMID**: Unified Mobile Application for Karnataka citizens
- **mHealth**: mHealth application for healthcare
- **Nirman Shahaka**: Building plan approval system

## 5. Office Automation (ಕಾನೂನು ಸ್ವಯಂಚಾಲಿತ)

- **MS Word**: Word processing
- **MS Excel**: Spreadsheet & calculations (formulas: SUM, AVERAGE, COUNT)
- **MS PowerPoint**: Presentations
- **MS Access**: Database management
- **MS Outlook**: Email & calendar

### Email Etiquettes (ಇಮೇಲ್ ನೈತಿಕತೆ)
- Use proper subject line
- Be concise in body
- Use attachments sparingly
- Avoid ALL CAPS (reads as shouting)

## 6. Cyber Security (ಸೈಬರ್ ಸುರಕ್ಷತೆ)

- **Malware**: Malicious software (virus, worm, trojan)
- **Phishing**: Fake emails/websites to steal data
- **Password**: Secret word/phrase for authentication
- **Firewall**: Network security system
- **Encryption**: Scrambling data for security
- **OTP**: One-Time Password — single-use verification code
- **Two-factor authentication (2FA)**: Extra security layer

> [!example] Likely Questions / PYQ
> Q: What is phishing? — Fake attempt to steal data
> Q: OTP stands for? — One-Time Password
