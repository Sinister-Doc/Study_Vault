## 1. General Kannada (ಸಾಮಾನ್ಯ ಕನ್ನಡ — `[P2-VAO-KAN-1.1]` to `1.6`)

### Q1. [Official KEA VAO Exam 27-10-2024, Paper-II, Q1 (A1)]
**Kannada Question:**
ಈ ಕೆಳಗಿನವುಗಳನ್ನು ಹೊಂದಿಸಿ ಬರೆಯಿರಿ:

| ಪಟ್ಟಿ I (ಅಕ್ಷರಗಳು) | ಪಟ್ಟಿ II (ಉಚ್ಚಾರಣಾ ಸ್ಥಾನಗಳು) |
| :--- | :--- |
| a. ಅ | i. ತಾಲವ್ಯ |
| b. ಟ | ii. ಕಂಠ್ಯ |
| c. ಯ | iii. ಓಷ್ಠ್ಯ |
| d. ಊ | iv. ಮೂರ್ಧನ್ಯ |

- (1) a-ii, b-iv, c-iii, d-i
- (2) a-ii, b-iv, c-i, d-iii
- (3) a-iv, b-i, c-ii, d-iii
- (4) a-iii, b-iv, c-i, d-ii

**Official KEA Answer: (2) a-ii, b-iv, c-i, d-iii**  
*Grammar Explanation:*
- `ಅ, ಆ` ಕಂಠ್ಯ ಧ್ವನಿಗಳು (ಉಚ್ಚಾರಣೆ ಗಂಟಲು/ಕಂಠದಿಂದ — ii)
- `ಟ, ಠ, ಡ, ಢ, ಣ` ಮೂರ್ಧನ್ಯ ಧ್ವನಿಗಳು (ನಾಲಗೆಯ ತುದಿಯು ಮುಂಭಾಗದ ಅಂಗಳಕ್ಕೆ ತಗುಲಿ ಉಚ್ಚಾರ — iv)
- `ಇ, ಈ, ಯ` ತಾಲವ್ಯ ಧ್ವನಿಗಳು (ನಾಲಗೆಯ ಮಧ್ಯಭಾಗ ತಾಲುವಿಗೆ ತಗುಲಿ ಉಚ್ಚಾರ — i)
- `ಉ, ಊ, ಪ, ಫ, ಬ, ಭ, ಮ` ಓಷ್ಠ್ಯ ಧ್ವನಿಗಳು (ತುಟಿಗಳ ಸಹಾಯದಿಂದ ಉಚ್ಚಾರ — iii).

### Q2. [Official KEA VAO Exam 27-10-2024, Paper-II, Q2 (A1)]
**Kannada Question:**
ಈ ಮುಂದಿನ ನಾಮಪದ ಮತ್ತು ಉದಾಹರಣೆಗಳ ಯಾವ ಜೋಡಿ/ಜೋಡಿಗಳು ಸರಿಯಾಗಿದೆ/ಸರಿಯಾಗಿವೆ?
- a. ರೂಢನಾಮ — ಉಡುಪಿ
- b. ಭಾವನಾಮ — ಕೆಂಪು
- c. ಅಂಕಿತನಾಮ — ನದಿ
- d. ದಿಗ್ವಾಚಕ — ತೆಂಕಣ

Choose the code:
- (1) a ಮಾತ್ರ
- (2) b ಮತ್ತು c
- (3) b ಮತ್ತು d
- (4) c ಮತ್ತು d

**Official KEA Answer: (3) b ಮತ್ತು d**  
*Grammar Explanation:*
- `ಉಡುಪಿ` ಒಂದು ನಿರ್ದಿಷ್ಟ ಸ್ಥಳದ ಹೆಸರು, ಆದ್ದರಿಂದ ಇದು **ಅಂಕಿತನಾಮ** (ರೂಢನಾಮವಲ್ಲ — a ತಪ್ಪು).
- `ಕೆಂಪು` ಗುಣ/ಭಾವವನ್ನು ಸೂಚಿಸುವ ಪದ, ಆದ್ದರಿಂದ ಇದು **ಭಾವನಾಮ** (b ಸರಿ).
- `ನದಿ` ರೂಢಿಯಿಂದ ಬಂದ ಸಾಮಾನ್ಯ ಹೆಸರು, ಆದ್ದರಿಂದ ಇದು **ರೂಢನಾಮ** (ಅಂಕಿತನಾಮವಲ್ಲ — c ತಪ್ಪು).
- `ತೆಂಕಣ` (ದಕ್ಷಿಣ) ದಿಕ್ಕನ್ನು ಸೂಚಿಸುವ ಪದ, ಆದ್ದರಿಂದ ಇದು **ದಿಗ್ವಾಚಕ** (d ಸರಿ).  
ಆದ್ದರಿಂದ ಸರಿಯಾದ ಜೋಡಿಗಳು **b ಮತ್ತು d (Option 3)**.

### Q3. [Official KEA VAO Exam 27-10-2024, Paper-II, Q3 (A1)]
**Kannada Question:**
ಈ ಕೆಳಗಿನ ಕ್ರಿಯಾಪದಗಳನ್ನು ಕಾಲದೊಂದಿಗೆ ಹೊಂದಿಸಿ ಬರೆಯಿರಿ:

| ಪಟ್ಟಿ I | ಪಟ್ಟಿ II |
| :--- | :--- |
| a. ತಿನ್ನುತ್ತೇನೆ | i. ಪ್ರಥಮ ಪುರುಷ ಭೂತಕಾಲ |
| b. ನಿಂತನು | ii. ಮಧ್ಯಮ ಪುರುಷ ಭವಿಷ್ಯತ್ ಕಾಲ |
| c. ನೋಡಿದೆ | iii. ಉತ್ತಮ ಪುರುಷ ವರ್ತಮಾನ ಕಾಲ |
| d. ಹಾಡುವಳು | iv. ಪ್ರಥಮ ಪುರುಷ ಭವಿಷ್ಯತ್ ಕಾಲ |

- (1) a-iv, b-i, c-ii, d-iii
- (2) a-iii, b-i, c-ii, d-iv
- (3) a-i, b-iv, c-ii, d-iii
- (4) a-ii, b-iii, c-iv, d-ii

**Official KEA Answer: (2) a-iii, b-i, c-ii, d-iv**  
*Grammar Explanation:*
- `ತಿನ್ನುತ್ತೇನೆ` — ಉತ್ತಮ ಪುರುಷ (ನಾನು), ವರ್ತಮಾನ ಕಾಲ (ಉತ್ತರ iii)
- `ನಿಂತನು` — ಪ್ರಥಮ ಪುರುಷ (ಅವನು), ಭೂತಕಾಲ (ಉತ್ತರ i)
- `ಹಾಡುವಳು` — ಪ್ರಥಮ ಪುರುಷ (ಅವಳು), ಭವಿಷ್ಯತ್ ಕಾಲ (ಉತ್ತರ iv).

### Q40. [Official KEA VAO Exam 27-10-2024, Paper-II, Q40 (A1)]
**English Question:**
Fill in the blanks:  
The receptionist ______ the information desk was both smart ______ polite.
- (1) in, but
- (2) at, and
- (3) at, but
- (4) within, although

**Official KEA Answer: (2) at, and**  
*Grammar Explanation:* Position at a specific service point takes the preposition **"at"** (*at the information desk*). The correlative construction **"both ... and"** links parallel positive traits (*both smart and polite*).

### Q41. [Official KEA VAO Exam 27-10-2024, Paper-II, Q41 (A1)]
**English Question:**
For a professional sportsperson, fitness is a must.  
Choose the correct question tag for the given statement.
- (1) Isn't he?
- (2) Isn't it?
- (3) Doesn't it?
- (4) Mustn't it?

**Official KEA Answer: (2) Isn't it?**  
*Grammar Explanation:* The subject of the sentence is the abstract noun clause **"fitness"** (singular neuter pronoun "it"), and the main verb is the affirmative auxiliary **"is"**. A positive statement takes a negative tag using the same auxiliary: **"isn't it?"**.

### Q42. [Official KEA VAO Exam 27-10-2024, Paper-II, Q42 (A1)]
**English Question:**
Change the following statement to Reported Speech:  
Ramu said, "My classmate wrote a letter to the Minister."
- (1) Ramu said that his classmate had written a letter to the Minister.
- (2) Ramu said that my classmate has written a letter to the Minister.
- (3) Ramu said that his classmate was writing a letter to the Minister.
- (4) Ramu said his classmate had wrote a letter to the Minister.

**Official KEA Answer: (1) Ramu said that his classmate had written a letter to the Minister.**  
*Grammar Explanation:* In indirect speech with a past reporting verb (*said*), simple past (*wrote*) shifts back to past perfect (*had written*), and the possessive pronoun *my* shifts to *his*.

## 3. Computer Knowledge (ಗಣಕ ಯಂತ್ರ ಜ್ಞಾನ — `[P2-VAO-COMP-3.1]` to `3.6`)

### Q82. [Official KEA VAO Exam 27-10-2024, Paper-II, Q82 (A1)]
**English Question:**
192.168.0.397 is an invalid IP address because:
- a. It starts with 192
- b. It has 0
- c. It has a number less than 500
- d. Any octet number cannot be more than 255

Choose the correct answer from the following codes:
- (1) Only d
- (2) Only c
- (3) a and b only
- (4) a and d only

**Official KEA Answer: (1) Only d**  
*Technical Explanation:* In IPv4 dotted-decimal notation, each of the four decimal numbers is an **8-bit octet**. An 8-bit unsigned integer can represent values strictly in the range $0$ to $2^8 - 1$, i.e., **0 to 255**. Because the 4th octet is **397**, it exceeds 255, rendering the IP address invalid.

### Q85. [Official KEA VAO Exam 27-10-2024, Paper-II, Q85 (A1)]
**English Question:**
Based on the "access time", arrange the following in ascending order:
- a. SSD
- b. HDD
- c. Main Memory
- d. Cache Memory

Options:
- (1) d, b, c, a
- (2) a, b, c, d
- (3) d, c, a, b
- (4) c, d, a, b

**Official KEA Answer: (3) d, c, a, b**  
*Technical Explanation:* "Access time" measures the latency to retrieve data. Shorter access time means faster memory:
1. **Cache Memory (SRAM):** $\approx 0.5 - 5$ nanoseconds (Fastest access time — d)
2. **Main Memory (DRAM):** $\approx 10 - 50$ nanoseconds (c)
3. **Solid State Drive (SSD / Flash):** $\approx 50 - 150$ microseconds (a)
4. **Hard Disk Drive (HDD / Mechanical):** $\approx 5 - 15$ milliseconds (Slowest access time — b)  
Ascending order of access time (shortest to longest): **d $\to$ c $\to$ a $\to$ b (Option 3)**.

### Q86. [Official KEA VAO Exam 27-10-2024, Paper-II, Q86 (A1)]
**English Question:**
Which of the following is true with respect to Read Only Memory (ROM)?
- a. Data stored in ROM and PROM chip cannot be altered by user.
- b. A user can erase data from EPROM.
- c. EEPROM is also known as flash memory.
- d. In EEPROM data cannot be erased.

Options:
- (1) a and c are correct
- (2) Only b is correct
- (3) c and d are correct
- (4) a, b and c are correct

**Official KEA Answer: (4) a, b and c are correct**  
*Technical Explanation:*
- `ROM` (Mask ROM) is factory written; `PROM` is OTP (one-time programmable by user/programmer) and cannot be modified after burning (statement a is correct).
- `EPROM` (Erasable Programmable ROM) data can be erased by exposing the quartz window to intense ultraviolet (UV) light (statement b is correct).
- `EEPROM` (Electrically Erasable Programmable ROM) can be erased electrically byte-by-byte; modern Flash memory is a high-density form of EEPROM that erases block-by-block (statement c is correct).
- Statement d is false because EEPROM data *can* be erased.  
Therefore, statements **a, b, and c are correct (Option 4)**.

### Q87. [Official KEA VAO Exam 27-10-2024, Paper-II, Q87 (A1)]
**English Question:**
The core of an Operating System (OS) is known as:
- (1) Shell
- (2) Kernel
- (3) MS-DOS
- (4) Console

**Official KEA Answer: (2) Kernel**  
*Technical Explanation:* The **Kernel** is the foundational core component of an operating system with complete control over everything in the system, managing hardware resources, memory, and CPU processes. The *Shell* is the user interface layer surrounding the kernel.

### Q88. [Official KEA VAO Exam 27-10-2024, Paper-II, Q88 (A1)]
**English Question:**
In an E-R diagram, double lines indicate:
- (1) Cardinality
- (2) Total participation
- (3) Multiple participation
- (4) Single participation

**Official KEA Answer: (2) Total participation**  
*Technical Explanation:* In Entity-Relationship (ER) database modeling, a **double line** connecting an entity set to a relationship set specifies **Total Participation** (existence dependency, where every entity in the set must participate in at least one relationship instance). A single line indicates partial participation.
