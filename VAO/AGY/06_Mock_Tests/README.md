# Interactive HTML Mock Tests — KEA VAO 2026

All mock tests are 100% self-contained, offline-ready single-file HTML applications engineered to replicate the official KEA examination testing environment.

---

## 1. Examination Architecture & Scoring Rules
- **Marking Scheme:** **+1.0 Mark** for each correct answer.
- **Negative Marking Penalty:** **-0.25 Mark (1/4th penalty)** deduction for every incorrect answer.
- **Unattempted Questions:** **0.00 Marks** (No penalty).
- **Timing Pacing:** Strictly calibrated to **72 seconds per question** matching the official KEA duration (120 minutes for 100 questions).

## 3. How to Launch & Use the Mock Tests
1. Double-click or open any `.html` file in any modern web browser.
2. No internet connection is required.
3. Timer begins automatically. Use the palette to navigate questions.
4. Click **Submit Examination** at any time to immediately view your net score, accuracy %, and full step-by-step explanations.
